📜 사용 전 동의 사항

본 프로그램(이하 "도구")을 사용하기 전 아래 세 가지 사항을 확인하고 동의해 주시기 바랍니다. 모든 고객 데이터는 사용자 본인의 브라우저(localStorage)에만 저장되며 어떤 외부 서버로도 전송되지 않습니다.
1. 개인정보 처리방침 (필수) ▼
제1조 (수집·저장하는 정보)

본 도구는 사용자가 직접 가져온 CRM 엑셀 파일에서 다음 항목을 사용자의 브라우저 저장소(localStorage)에 캐싱합니다:

  • 고객 성명·연락처·차종·트림·거주지·직장·진행상태·가망등급
  • 최초상담일·계약일·출고일·등록번호·결제방식·약정기간·보험만기·메모

사용자 본인의 정보로 딜러명·직급·딜러사·전시장명·연락처·전시장주소·테마색이 별도 저장됩니다.

제2조 (외부 전송 금지)

본 도구는 위 정보를 외부 서버로 일절 전송하지 않으며 수집하지 않습니다. 모든 처리는 사용자 단말의 브라우저 내에서만 이루어집니다. 단, SheetJS 라이브러리가 cdn.sheetjs.com에서 1회 로드되나, 이는 코드 모듈일 뿐 사용자 데이터는 함께 전송되지 않습니다.

제3조 (사용자의 의무 — 개인정보 보호법 준수)

본 도구를 사용하는 영업사원(이하 "사용자")은 개인정보보호법상 개인정보처리자의 지위를 가지며 다음 의무를 부담합니다:

  1. 고객의 개인정보를 영업 목적으로 사용함에 있어 별도의 수집·이용 동의를 받을 것
  2. 고객의 열람·정정·삭제 요청 시 즉시 처리할 것
  3. 단말 분실·도난·매각 시 사전에 데이터를 삭제할 것 (CRM 패널의 🗑 버튼 또는 브라우저 데이터 삭제)
  4. 고객 데이터를 제3자에게 공유·양도하지 않을 것
제4조 (보관 기간 및 파기)

사용자가 직접 캐시를 비우거나 브라우저 데이터를 삭제할 때까지 보관됩니다. 사용자가 도구 내 "캐시 비우기" 또는 "전체 초기화"를 실행하면 즉시 파기됩니다.

제5조 (책임의 범위)

본 도구는 데이터 보관소(저장·전송 인프라)가 아닌 텍스트 생성 도구입니다. 사용자가 브라우저에 저장한 데이터의 보안·암호화·백업 책임은 사용자 본인에게 있습니다.

2. 이용약관 (필수) ▼
제1조 (라이선스 범위)
  1. 본 도구의 라이선스는 1인 1라이선스이며 영업 활동을 수행하는 본인에 한하여 사용 가능합니다.
  2. 라이선스 양도·재판매·재배포·임대·공유는 금지됩니다.
  3. HTML 코드의 무단 복제·역공학·수정 후 재배포는 저작권 침해에 해당합니다.
제2조 (허용 범위)
  1. 본인이 담당하는 자동차 영업 활동 (신차·중고차·리스·렌트 등)
  2. 본인이 직접 만든 변수·템플릿의 추가·수정·백업
  3. 본인이 보유한 CRM 엑셀 파일을 가져와 처리
제3조 (금지 사항)
  1. 스팸·광고성 정보 일괄 전송 등 정보통신망법·전자상거래법 위반 행위
  2. 고객의 사전 동의 없는 영리적 마케팅 메시지 발송
  3. 본 도구를 이용한 불법·반사회적 행위
제4조 (업데이트 정책)

구매 시 명시된 라이선스 정책에 따라 무료 또는 유료 업데이트가 제공됩니다. 자세한 사항은 구매 안내문을 따릅니다.

제5조 (환불 정책)

전자상거래법에 따라 결제일로부터 7일 이내, 사용 흔적이 없는 경우 전액 환불 가능합니다. 단 라이선스 키가 활성화된 후에는 디지털 콘텐츠 특성상 환불이 제한될 수 있습니다.

제6조 (라이선스 종료)

제1조·제3조를 위반할 경우 라이선스가 즉시 종료되며, 별도 통보 없이 사용이 중지될 수 있습니다.

3. 면책 조항 (확인) ▼
1. 도구의 성격

본 도구는 영업 보조용 텍스트 생성기이며, 카카오톡·SMS 등 통신사 서비스 자체와는 무관합니다. 생성된 문자는 사용자가 직접 복사하여 원하는 채널로 발송해야 합니다.

2. 데이터 손실

다음과 같은 경우 데이터가 손실될 수 있으며, 이에 대한 책임은 사용자 본인에게 있습니다:

  • 브라우저 데이터 자동 삭제(시크릿 모드·캐시 정리·확장 프로그램)
  • 단말 초기화·교체
  • localStorage 용량 한도 초과

중요한 사용자 템플릿은 도구 내 📤 백업 내려받기 기능으로 정기 백업하시기 바랍니다.

3. 정확성 보장

변수 자동 치환 결과(D+일수·출고연수·보험만기 등)의 정확성은 사용자가 발송 전 반드시 검증해야 합니다. 본 도구의 결과로 발생한 영업·계약·고객 응대상의 손해에 대해 개발사는 책임을 지지 않습니다.

4. 영업 성과

본 도구는 영업 활동의 효율화를 돕는 보조 수단이며, 영업 실적·매출·계약 성공률을 보장하지 않습니다.

5. 분쟁 해결

본 도구의 사용과 관련하여 분쟁이 발생할 경우, 사용자의 주소지 관할 법원을 합의관할로 합니다. 본 약관은 대한민국 법령을 따릅니다.
